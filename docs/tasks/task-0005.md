# Relation mode

- A single activated circle shows a round `+` button (lower-right, same
  counter-scaled size as the former `i`, pointer cursor, Enter/Space works). The Connect
  toolbar button starts the same mode (one code path, `startRelation`).
- In relation mode a dashed live line follows the pointer (last touch point on
  touch), correct under pan/zoom/wheel; the source circle is highlighted, the
  cursor is a crosshair, `+` and the infobox are hidden.
- Click another circle: relation created (no self-links, duplicates ignored),
  mode ends, target activated. Cancel without creating: right click, click the
  source again, Esc, click empty canvas or a line, Connect again.
- Cursors: hover circle/empty canvas `grab`; dragging a circle, group or
  panning `grabbing` (root class, survives leaving the element); marquee keeps
  `crosshair`.

# Infobox and "activated"

- The description drawer is now the infobox. It shows automatically when
  exactly one circle or line is activated (not in relation mode): type hint,
  editable name (circle name or relation name, live autosave, never
  autofocused), "from -> to" for lines, description textarea for circles.
  Esc deactivates and hides it. The round `i` button is gone (task-0004's `i`
  is superseded); circles with a description show a small accent dot.
- "Activated" (clicked element or group) replaces "selected" / "selection" in code and
  docs: `activated`, `.activated`; see
  `docs/product/concepts/interaction.md`.
