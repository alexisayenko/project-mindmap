# Locked relations

- A relation has `locked: boolean` (default `false`; missing means `false`). It is saved in localStorage and in Export JSON.
- Infobox of a relation: a padlock button (drawn SVG, open or closed, pointer cursor, tooltip "Lock" / "Unlock", `aria-pressed`) next to the direction button toggles it.
- Canvas: no marker; a locked relation looks like any other (the lock state is visible only in the infobox button).
- Dragging a circle moves the whole connected component reachable through locked relations (any depth, either direction of the relation), rigidly: every member keeps its offset to the dragged circle. Unlocked relations do not propagate. The moving set is a set of circle ids, so a circle that is both activated and locked-connected moves once. Dragging one circle of an activated group still moves the whole group, plus everything locked to any member.
- Positions are saved on pointerup, as before; dragging re-renders on every move.
- Unlock: the next drag no longer carries the other side.

## Mirrors audioplayer "Genres map v2"

Audioplayer (`web/js/genre-force-view.js`, option `rigid: true`, tests in `genre-force-view.test.mjs`): dragging a parent makes all its descendants (any depth) follow and settle at their original offsets, dragging a child moves only itself, drops stay put. There is no lock flag there; the mind map adds an explicit per-relation flag and makes the link symmetric (either end drags the other). Locked followers use the same damped spring (`FOLLOW` constants at the top of `web/app.js`, stiffness 90 / damping 8, 8 ms fixed step): they lag the pointer and settle at their offsets; the rAF loop stops when all are at rest (distance < 0.02, speed < 0.05). On pointerup the target positions are saved at once, and again when the loop rests. `prefers-reduced-motion` moves them instantly.
