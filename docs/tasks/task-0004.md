# Concept description

Extends the v0 canvas in `web/`.

## Done

- Each entity has a top-level `description` (plain text, default empty;
  `properties` stays reserved for key/value data). Old saved data without
  it loads as empty; Export JSON includes it.
- Every circle has a round `i` button on its upper-right edge, counter-scaled
  so it keeps a readable size at any zoom; filled with the accent colour when
  the description is non-empty. Focusable, `aria-label` "Show description of
  <name>"; Enter/Space opens it. Pressing it does not drag, select or connect.
- Description panel: right-side drawer on wide screens, bottom sheet on narrow
  ones. Shows the concept name and a textarea (focused on open) with debounced
  autosave to localStorage. Closes via Close, Esc, a click outside, or
  deletion of the entity.
- Relation names: relations get a top-level `name` (default empty, old data
  loads as empty, exported). Double-click / double-tap a line (14px+ invisible
  hit area) selects it and opens the inline editor at its midpoint; Enter or
  blur commits, Esc cancels, empty = no label. The name is drawn as a
  label with a background pill at the midpoint, rotated along the line
  (angle normalised to (-90, 90], never upside down); the editor stays horizontal.
