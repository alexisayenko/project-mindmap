# v0 canvas

The simplest useful canvas in `web/` (`index.html`, `app.js`,
`style.css`; no framework, no build step, no dependencies).

## Done

- Full-window SVG canvas; double-click / double-tap on empty space
  creates a circle "New concept" and opens inline rename.
- Drag to move (pointer events, mouse and touch); radius fits the label.
- Rename by double-click; Enter / blur commits, Esc cancels.
- Connect: activate a circle, press + or the Connect button,
  then click another circle; a straight line joins the circle edges.
- Activate a circle or line; Delete / Backspace or the Delete button
  removes it (a circle takes its lines with it). No confirmation, no undo.
- Autosave to localStorage key `mindmap.v0`; Clear (confirm); Export JSON.
- Light / dark via `prefers-color-scheme`; phone-width layout.

## Data model

`{version: 0, entities: [{id, name, x, y, properties: {}}], relations: [{id, from, to}]}`.
`properties` is reserved; no UI yet.

## Not yet

Arrowheads and relation kinds, regions, levels, properties UI, undo,
force layout.
