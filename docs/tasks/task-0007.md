# Semantic zoom

- Constant-size content (mode `'constant'`, not the default): positions scale with zoom `k`, but circle radius, text and relation labels use factor `k^0.25` clamped to 0.8x-1.4x of base screen size (constants `SIZE_EXP`, `SIZE_MIN`, `SIZE_MAX`); strokes, arrowheads and the `+` button stay constant screen size. Overlapping circles at low zoom are accepted. Zoom re-renders (`zoomAt`, Reset view).
- `ZOOM_MODE` (top of `web/app.js`): `'geometric'` (default: circle radius scales with `k`; text, labels and snippet keep a constant screen size) or `'constant'` (circle radius and text follow the `k^0.25` clamped rule above). Thresholds apply in both.
- Level of detail, constants at the top of `web/app.js` (`LOD_NAMES` 0.45, `LOD_DESC` 1.8): `k < 0.45` circles and lines only (no names, no relation labels; the hover tooltip still gives the full name); `0.45 <= k < 1.8` names and relation labels; `k >= 1.8` also the first ~60 characters of the description (wrapped, small, below the circle, truncated with an ellipsis). The small description dot shows instead below that level.
- Hit areas, dragging, relation mode, marquee and infobox are unchanged at every level.
