# Pan, zoom and group activation

Extends the v0 canvas in `web/` (still plain JS + SVG, no dependencies).

## Done

- One world `<g>` with `translate + scale`; pointer coordinates are
  converted to world coordinates for create, drag, marquee and the
  rename overlay (repositioned on pan/zoom/resize).
- Pan: drag empty canvas (mouse and touch). A click without movement
  clears the activation; double-click on empty space still creates a
  circle at the world position under the pointer.
- Zoom: plain wheel, Ctrl/Cmd+wheel and trackpad pinch zoom around the
  cursor (0.2x-4x, non-passive listener, page zoom prevented); Shift+wheel
  or Alt+wheel pans (Shift swaps deltaY into deltaX on some browsers).
  Ctrl+wheel cannot be told apart from pinch, so it zooms.
  Toolbar `-`, `+`, `Reset view` and a zoom percent readout.
- Strokes use `vector-effect: non-scaling-stroke`; labels scale with
  their circle.
- View persisted as optional `view: {x, y, k}` under `mindmap.v0`
  (version stays 0; missing view = defaults); Export JSON includes it.
- Group selection: Shift, Ctrl, Alt or Meta+drag on empty canvas draws a marquee (circles
  whose centre is inside, plus relations with both ends inside);
  Shift+click toggles a circle or line; Ctrl/Cmd+A selects all; the
  marquee is only started with a modifier key (the former toolbar `Activate` toggle was removed in task-0006).
- An activated group moves together when one member is dragged; Delete /
  Backspace / Delete button remove the activated elements with attached lines.
  Shift+click no longer connects (it toggles activation).
