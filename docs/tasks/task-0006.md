# Relation direction

- Relation gets `dir`: `"none"` | `"forward"` (from -> to) | `"backward"` | `"both"`. Missing = `"none"`; version 0 unchanged, no migration. New relations are `"none"`. Export JSON includes it.
- Infobox row for a relation: the connector between the two names is a button showing the direction as an inline SVG (line plus filled triangle heads, no text glyphs). It opens a custom popover with four same-size SVG options (plain line, left, right, both), current one highlighted; closes on choose, Esc or outside click.
- Canvas: filled triangle arrowheads at the circle edge (not the centre) at the proper end(s); the line stops at the arrowhead base. Label-above-line layout unchanged.
